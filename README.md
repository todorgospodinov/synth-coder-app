# Code Trainer Studio

# Create an empty multi-age app

I want to create "CodeTrainer" app to publish  programing task on Python online with AI assistance for create and checking Python tasks.

  - Use multi-page structure: each app screen is a separate page with a different URL.

  - Use modular design to enhance maintainability: the app is composed of modular components, each with a well-defined responsibility and minimal dependencies.

  - Technologies: TypeScript, React, Vite, Tailwind, Supabase.

I want to build the app step-by-step. Let's start with the first step:

  - Create an empty multi-page app with modular component structure: header, home page, footer.

  - Keep the home page empty at the start.
